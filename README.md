# 学习通悬浮窗

**桌面边缘的一个小球：点开就是学习通，做题时调用 AI 逐题作答并自动填入。**

![version](https://img.shields.io/badge/version-1.4.0-blue)
![platform](https://img.shields.io/badge/Windows-10%20%7C%2011-0078D4)
![size](https://img.shields.io/badge/installer-120%20MB-lightgrey)
![downloads](https://img.shields.io/github/downloads/kucpy6/cxball-updates/total)

不装浏览器插件，不改学习通客户端，不注入进程——只在你自己的电脑上开一个小窗口，常驻桌面，随用随开。

## 下载安装（约 1 分钟）

### 👉 [**点这里下载最新版**](../../releases/latest)

或者手动下载：进 [Releases](../../releases) → 选最新版本 → 下载 `cxball-setup-x.y.z.exe`

1. 双击下载好的 `cxball-setup-1.4.0.exe`
2. 选择安装目录（默认 `D:\学习通悬浮球`），按需勾选桌面 / 开始菜单快捷方式
3. 装完从桌面图标启动，首次启动约 5 秒自动完成环境准备

> **首次运行会被 Windows 拦截**：出现「Windows 已保护你的电脑」时，点 **更多信息 → 仍要运行**。原因是程序没有购买代码签名证书，不是文件有问题。

### 更新

- **已经装过 1.4.0 或更新版本**：打开面板 → 设置 → 「版本更新」→ 检查更新 → 立即更新。程序自动下载替换并重启，**账号、Cookie、设置全部保留**，不需要卸载重装。
- **装的还是 1.3.x 及更早版本**：那版本里没有更新入口，需要下载上面最新安装包**覆盖安装一次**（不用先卸载，数据不丢）。之后所有升级都在面板里点。

### 卸载

Windows「设置 → 应用 → 已安装的应用」里找到「学习通悬浮窗」卸载。
账号和配置留在 `data\` 目录，想彻底清干净就手动删掉整个安装目录。

## 它能做什么

| 功能 | 说明 |
| --- | --- |
| 🟢 悬浮球常驻 | 始终置顶、不占任务栏，可拖动，点一下展开/收起 |
| 🌐 内置浏览器 | 直接登录学习通上课、看资料、写作业，无需切换窗口 |
| 🤖 AI 逐题作答 | 支持单选、多选、判断、填空，识别题目后作答并自动填入 |
| 🎯 两遍作答 + 裁决 | 每题独立做两遍，结果不一致时交给更强的模型重判，减少偶发错误 |
| 📄 文档批量下载 | 一键把课程资料下载到本地 |
| 🔄 一键更新 | 面板内完成升级，不丢数据 |

## 系统要求

- Windows 10 1809+ / Windows 11
- 需要 WebView2 运行时（Win10 1903 与 Win11 已内置，更老的系统装完会提示）
- 约 300 MB 磁盘空间

## 常见问题

**Q：提示「Windows 已保护你的电脑」，是不是有毒？**
不是。这是因为没有代码签名证书，Windows 对新下载的 exe 一律拦截。点「更多信息 → 仍要运行」即可。文件指纹可以在 Release 页面核对（SHA256）。

**Q：程序会不会上传我的账号密码？**
不会。登录态和 Cookie 存在本机 `data\` 目录，只有题目内容会发给 AI 模型用于作答。

**Q：检查更新一直转圈？**
程序会依次尝试 Gitee、jsDelivr、GitHub 三个更新源，都连不上才会失败。一般是本地网络或运营商对 GitHub 的阻断，换个网络再试。

**Q：做题时没有反应？**
确认学习通页面已经打开并加载完成，再点「开始作答」。如果窗口里提示调试端口未连接，关掉悬浮球窗口，从桌面图标重新启动一次即可。

**Q：程序会自动提交作业吗？**
不会。只负责把答案填进去，检查确认后由你自己点提交。

## 这个仓库是什么

本仓库是**在线更新源**，不是源码仓库。程序通过这里检查新版本。

| 文件 | 作用 |
| --- | --- |
| `latest.json` | 版本清单：版本号、日期、包大小、SHA256 |
| `cxball-x.y.z.zip` | 增量更新包，只含界面与做题逻辑（几百 KB） |
| `preview.png` / `panel.png` | 界面截图 |

程序本体（安装包）在 [Releases](../../releases) 里，因为 GitHub 仓库单个文件限制 100 MB，120 MB 的安装包放不进仓库。

更新包只覆盖界面与做题逻辑。涉及启动器、运行时这类底层文件的改动会以新安装包发布，程序会提示改为覆盖安装，避免新旧文件混搭。
